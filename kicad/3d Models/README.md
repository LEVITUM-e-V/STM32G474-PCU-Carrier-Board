# 3D models

The four Molex Micro-Fit 3.0 STEP models are not in the repository, because they are Molex files and not ours to redistribute. The board works without them; only the connectors are missing in KiCad's 3D view.

To get them, download the STEP file for each part number from molex.com (product page → "3D Models") and save it here under exactly this name:

| File name | Molex part | Used by |
|---|---|---|
| `430450400.stp` | 43045-0400 (2×2) | J1 |
| `430450800.stp` | 43045-0800 (2×4) | J2, J9, J10 |
| `430451000.stp` | 43045-1000 (2×5) | J8 |
| `430451200.stp` | 43045-1200 (2×6) | J3 |
